# Project Charter

Date: 2026-01-15
Owner: Product Owner

## Purpose

Operate and evolve the Click CLI Toolkit, an internal build of the Python package for composable command line interfaces with nested commands, automatic help pages and lazy subcommand loading.

## Goals

Ship 8.5.0 by end of August 2026, keep the runtime dependency-free, and prepare the 9.0 removals.

## Out of Scope

Argument parsing for non-Python tools and graphical interfaces.

## Success Measures

Coverage at least 95 percent, zero open blocker defects at release, and completion available for four shells.

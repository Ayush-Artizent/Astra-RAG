# Documentation Writing

Rules for authoring project documents.

## Style

Docs are Markdown with MyST roles. Examples must be runnable and use `import click` at the top.

## Headers

Every project document starts with a `Date:` line in ISO format and an `Owner:` line. Emails add From and To; meetings add Attendees.

## Superseded Documents

A document replaced by a newer one carries a first line `Status: SUPERSEDED by <id>` and is kept for traceability only.

# Data Retention Compliance Note

Date: 2026-03-12
Owner: Compliance Lead
Status: Approved

## Cache retention

Caches storing customer-derived values expire within 24 hours using expireAfterWrite. The compliance check reads cache configuration from the metrics platform monthly.

## Evidence

Evidence is the cache region inventory, 200 regions as of 2026-03-01, of which 37 hold customer-derived data.

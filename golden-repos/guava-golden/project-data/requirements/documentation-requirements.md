# Documentation Requirements

Date: 2026-02-02
Owner: Documentation Lead
Status: Approved

## REQ-DOC-001 javadoc site

A versioned Javadoc site shall be published for each release within one business day.

## REQ-DOC-002 migration guides

Each deprecation shall include a migration guide with before and after code.

## REQ-DOC-003 search

The documentation portal shall return results for class names within 500 ms at p95. Open: add semantic search is to decide.

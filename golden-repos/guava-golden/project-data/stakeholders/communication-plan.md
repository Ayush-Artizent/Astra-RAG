# Communication Plan

Date: 2026-01-12
Owner: Program Manager

## Cadence

Governance Board meets every two weeks. Release announcements go out on each publication date. A monthly consumer forum is hosted by the Documentation Lead.

## Channels

Release notes in the documentation portal, announcements by email to the consumer distribution list, incident updates in the platform status channel.

## Escalation

Level 1 Core Collections Lead, level 2 Platform Architect, level 3 Sponsor. Security issues go directly to the Security Architect.

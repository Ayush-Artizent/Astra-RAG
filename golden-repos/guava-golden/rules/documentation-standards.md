# Documentation Standards

Owner: Documentation Lead. Date: 2026-03-23.

## Structure

Rules for document structure.

### Required sections

Every BRD, test plan and design spec must include purpose, scope, owner, date, status and open items. Open items are written as Open: lines.

### Status values

Status is one of Draft, In Review, Approved, Superseded. A Superseded document must name its replacement in the first paragraph.

## Style

Rules for style.

### Javadoc

Public classes in com.acme.platform.guava require Javadoc with a since tag and a thread-safety statement.

### Examples

Code samples must compile against the published GPL version and show imports.

# Email: Node.js 18 end of life

Date: 2026-03-02
From: Platform Operations Manager
To: LimitKit Tech Lead
Cc: LimitKit Release Manager

## Notice

Node.js 18 is past end of life across all internal runtimes as of this date. Operations will not certify LimitKit builds on Node.js 18 any longer.

## Ask

Confirm that the next release can declare `engines.node` as `>=20`.

## Reply summary

The Tech Lead confirmed on 2026-03-04 that Node.js 20 becomes the minimum. This is tracked as LIM-220 and recorded in requirements v2.

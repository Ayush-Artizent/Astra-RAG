# Business Requirements Document

## Purpose

State the business problem the LimitKit change addresses and who asks for it.

## Scope

List what is in scope and out of scope for this change to the concurrency limiter.

## Functional requirements

Use ids `REQ-NNN`. Each requirement states the API surface touched, for example `pLimit`, `limit.map`, `limitFunction`.

## Non-functional requirements

Use ids `NFR-NNN`. Cover Node.js version, dependency budget, and bundle size.

## Risks and assumptions

Reference RAID ids `R-NNN`, `A-NNN`.

## Approvals

Name the product owner and the release manager.

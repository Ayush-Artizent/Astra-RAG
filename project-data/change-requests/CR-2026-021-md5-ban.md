# Change Request CR-2026-021: Enforce Hashing.md5 ban in the build

Date: 2026-03-10
Owner: Security Architect
Status: Approved on 2026-03-18

## Summary

Add an Error Prone check that fails the build on Hashing.md5() and Hashing.sha1() outside an allow-list of the partner gateway module.

## Impact

41 call sites across 17 repositories must migrate to sha256 or crc32c. Teams have until 2026-03-31.

## Open items

Open: allow-list expiry date depends on the partner gateway retirement.

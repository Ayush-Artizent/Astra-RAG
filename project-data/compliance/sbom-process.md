# SBOM Process

Date: 2026-01-28
Owner: Compliance Lead
Status: Approved

## Format

Each GPL release publishes a CycloneDX 1.5 SBOM in JSON alongside the jar. The SBOM lists guava, failureaccess 1.0.2, jspecify and error_prone_annotations with versions and licenses.

## Timing

The SBOM is generated by the release pipeline and attached to the release before publication. Missing SBOM blocks release.

## Open items

Open: whether test-scope dependencies appear in the SBOM is to decide.

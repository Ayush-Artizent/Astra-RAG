# Stakeholder Register

Date: 2026-01-20
Owner: LimitKit Product Owner

## Register

| Role | Interest | Influence | Engagement |
|---|---|---|---|
| Product Owner | Scope and priorities | High | Weekly |
| Tech Lead | Design and quality | High | Daily |
| Release Manager | Release gates | Medium | Per release |
| QA Lead | Test coverage | Medium | Weekly |
| Payments Platform Lead | Primary consumer | High | Per change request |
| Platform Operations Manager | Runtime certification | Medium | Monthly |
| Documentation Lead | Readme and migration guide | Low | Per release |

## Escalation path

Issues go first to the Tech Lead, then the Product Owner, then the Change Advisory Board.

# Stakeholder Register

Date: 2026-02-10
Owner: Product Owner

## Product Owner

Role: sponsor. Approves Major releases and change requests. Influence high, interest high.

## Release Manager

Role: runs the release checklist and approves releases with a Maintainer. Influence high, interest high.

## Maintainer

Role: owns the code in `src/click` and reviews pull requests. Rotates weekly.

## QA Lead

Role: owns the test plan and coverage threshold of 95 percent.

## Documentation Lead

Role: owns nomenclature and the upgrade guides.

## Security Lead

Role: owns the dependency policy and vulnerability triage within 3 business days.

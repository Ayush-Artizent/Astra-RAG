# timeline/

Living record of where Astra-RAG development stands. Read this folder before starting work;
update it before finishing work (rules in `../CLAUDE.md`).

| File | Purpose | Update when |
|------|---------|-------------|
| `CURRENT_STATE.md` | What the repo does *right now* (snapshot, overwritten) | Behaviour, structure, deps or endpoints change |
| `TASKS.md` | Workstreams and task status (todo / doing / done) | A task starts, moves or finishes |
| `CHANGELOG.md` | Dated, append-only log of what changed and why | Every meaningful change (newest first) |
